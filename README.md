# Pulse Music

Installers for **Pulse Music**, a liquid-glass desktop client for Spotify (Windows).

**Download:** open [Releases](../../releases/latest) and get `PulseMusic-Setup-<version>.exe`.

Once installed, the app updates itself from this page.

## Before you install

- You need **Spotify Premium**.
- The app is in Spotify's development mode, so your Spotify account must be added by the author first. Ask Nix to add you.
- Windows may show "Windows protected your PC" because the installer isn't code-signed: click *More info* → *Run anyway*.
- The installer can set up the **AI DJ** (Ollama + a language model, about 5 GB). You can skip it and do it later in Settings → AI DJ.
